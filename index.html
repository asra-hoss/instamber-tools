Instamber lookup engine — demo

Working schematic of the five sibling tools for instamber.com. One shared engine (lookup.js + data.json), five framings. Data: NANPA & Canadian Numbering Administrator public records. Demo page only — the live tools will live on instamber.com.

1 · Carrier Lookup

Carrier, line type and region for any US/Canadian number.

2 · VoIP Number Checker

Answers one question: is this a VoIP (internet/app) line?

3 · Google Voice Number Lookup

Checks the number's block against the carriers Google Voice uses.

4 · Text App Number Checker

Flags numbers from TextNow, TextFree and other texting-app suppliers.

5 · Area Code Lookup

State/province, country, time zone and main city for an area code.
